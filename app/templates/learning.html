Using GROUP BY to Summarize Survey Responses

In large-scale surveys, you'll often need to summarize responses by district, sector, or enumeration block. The GROUP BY clause lets you collapse rows sharing a common value into aggregate rows, so you can apply functions like COUNT(), SUM() and AVG() per group.

Example — Households surveyed per district 
SELECT district, COUNT(*) AS households_surveyed
FROM nss_survey_responses
GROUP BY district
ORDER BY households_surveyed DESC;

Notice that every column in the SELECT list must either be inside an aggregate function or listed in the GROUP BY clause — this is the most common source of errors for new analysts.
